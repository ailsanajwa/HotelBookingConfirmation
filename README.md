The project focuses on translating a provided design into a functional and responsive web interface with interactive navigation and booking information.

## Overview

### The challenge

This project is a solution to the [Hotel Booking Confirmation Page challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/hotel-booking-confirmation-page).

The goal was to build a responsive hotel booking confirmation interface based on the provided design while maintaining a clean and intuitive user experience.

Users should be able to:

- View the optimal layout depending on their device's screen size
- See hover and focus states for interactive elements
- Open and close the navigation menu on smaller screens
- View their hotel booking information
- View arrival, Wi-Fi, breakfast, and weather information
- Copy the Wi-Fi password using the copy button
- Interact with the navigation menu
- Use the print receipt functionality

### What I learned

This project helped me improve my understanding of responsive frontend development and interactive user interfaces.

During the development process, I practiced:

- Translating a visual design into a functional webpage
- Creating responsive layouts using CSS Grid and Flexbox
- Building structured and reusable UI sections
- Creating responsive navigation for desktop and mobile
- Implementing JavaScript interactions
- Creating a copy-to-clipboard interaction
- Implementing a print receipt function
- Improving typography, spacing, and visual hierarchy
- Testing layouts across different screen sizes

One of the main challenges was creating a navigation system that works smoothly on both desktop and mobile devices.
